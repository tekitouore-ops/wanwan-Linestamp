# samples/ について

このフォルダは、動作確認用の実画像サンプルを**手元で**置くためのものです。
バイナリのテスト画像はリポジトリにコミットしません(`.gitignore` で `samples/*` を除外、
この README のみコミット対象)。

## 置いてほしいファイル

| ファイル名(例)            | 用途                                                                                         |
| ------------------------- | -------------------------------------------------------------------------------------------- |
| `reference-character.png` | タブ①で使う参照キャラクター画像(1枚)                                                         |
| `generated-sheet-01.png`  | ChatGPTで生成した6列×4行のスタンプシート画像                                                 |
| `generated-sheet-02.png`  | (あれば)別パターンのシート画像。列ズレや背景色が違うものがあると検出アルゴリズムの確認に有用 |

## 手動確認の手順(Phase 3以降)

1. タブ①で参照画像として `reference-character.png` を登録し、適当な24行を入力してプロンプトを生成する。
2. 生成したプロンプトと参照画像を実際にChatGPTに渡し、シート画像を生成する(または、ここに置いた `generated-sheet-*.png` を使う)。
3. タブ②でシート画像をアップロードし、自動検出→24個の枠が妥当か目視確認する。
4. 検出結果エディタで枠を微調整し、プレビュー(市松模様・白・ダーク背景)を確認する。
5. 「ZIPで書き出し」を実行し、`01.png`〜`24.png` が規格(370×320以下・偶数・透過PNG・1MB以下)を満たしているか確認する。

サンプルが無い場合、自動テスト(Vitest)はコード内で合成した画像を使うため実行可能ですが、
実際のAI生成画像特有の癖(色のにじみ、列のずれ等)の確認にはサンプル画像が必要です。
