# 仕様書(spec)

本ドキュメントは、プロジェクト指示のうち要件部分(目的・利用フロー・機能1・機能2・LINE規格・UI要件)を整理したもの。
仕様を変更した場合は、本ファイルとREADME.mdを同時に更新すること。

## 1. 目的

LINEスタンプ(静止画24個セット)の制作を助けるブラウザツール。

1. 参照キャラクター画像1枚と、24個分の「お題・状況・セリフ」から、ChatGPT画像生成に渡す日本語プロンプトを作る(機能1)。
2. ChatGPTが生成した「24個のスタンプが1枚に並んだシート画像」(6列×4行)を自動検出で24枚に切り出し、微調整し、LINEスタンプ規格のPNG(透過)にしてZIPで書き出す(機能2)。

画像生成そのものはツール内では行わない。プロンプトを作るだけで、生成はユーザーがChatGPT上で行う。

## 2. 利用フロー

1. 【タブ①】参照画像を登録し、24行の表に「お題・状況・セリフ」を入力する。
2. 「プロンプトを生成」→「コピー」。
3. ChatGPTに参照画像を添付し、コピーしたプロンプトを貼って生成する。
4. 生成された1枚のシート画像をダウンロードする。
5. 【タブ②】シート画像をアップロードし、自動検出→微調整→プレビュー確認。
6. 「ZIPで書き出し」→ 01.png〜24.pngが入ったZIPを取得する。

## 3. 機能1: プロンプト生成(タブ①)

### 入力
- 参照画像: D&D/ファイル選択で1枚登録。プレビュー・差し替え・削除可能。メモリ上のみ保持(リロードで消える)。プロンプトには画像を埋め込めないため、「ChatGPTに参照画像も添付してください」という案内を常時表示する。
- 24行の入力表(No.固定、お題/状況/セリフ)。未入力行は警告するが生成は可能。
- CSV/TSV貼り付け(列順: お題,状況,セリフ。ヘッダー有無自動判定。引用符・カンマ・改行対応。24行超過は無視して警告、不足は空欄)。
- CSVテンプレートのダウンロード。
- 共通設定: キャラクター補足、書体イメージ(選択式+自由入力)、文字色(既定#5A3A22)、文字の縁取りON/OFF(既定ON)、背景色(既定#FFFFFF)、「プロンプトで白フチを指示する」(既定OFF)、追加指示、グリッド(cols×rows、UI上は6×4固定だが内部は可変)。
- 入力内容・共通設定はlocalStorageに自動保存(画像は保存しない)。

### 出力
- プロンプト全文を読み取り専用テキストエリアに表示、文字数表示、クリップボードコピー(トースト通知)。
- プロジェクトのJSON保存/読込(入力表+共通設定、versionフィールドあり)。
- 個別再生成プロンプト(各行、余力があれば実装)。

### プロンプトテンプレート
詳細は `docs/prompt-template.md` を参照。

## 4. 機能2: 分割・書き出し(タブ②)

### 入力
- シート画像(PNG/JPEG/WebP)。想定1536×1024前後、最大4096px程度まで対応(超える場合は検出用に縮小コピーを使用、切り出しは元解像度)。

### 自動検出アルゴリズム(概要。詳細はdocs/architecture.mdを参照)
1. 前景マスク作成(背景色推定→差分しきい値→連結成分ラベリングでノイズ除去)。
2. グリッド境界検出(投影法。失敗時は等分割フォールバック)。
3. セルごとのbbox算出+警告フラグ(空セル・境界接触・サイズ異常)。

### 検出結果エディタ
- 枠の選択・移動・リサイズ・矢印キー移動・ズーム/パン。
- 「描き直す」「内容にフィット」「番号の入れ替え」「再検出」「リセット」。
- 検出パラメータ(しきい値/最小面積/検出方式)のスライダー。
- Undo/Redo(余力があれば)。

### 描画パイプライン(renderStamp.ts、プレビューと書き出しで共用)
1. 切り出し(枠外は強制的に背景扱い)
2. 背景透過(フラッドフィル方式、内部の白領域は保持)
3. 配置(余白・拡大率・オフセット・揃え)
4. 白フチ(アルファ膨張、ツール側で付与。AIへの指示は既定OFF)
5. 解像度不足バッジ表示(実効1.3倍超の拡大時)
6. 出力サイズは偶数に丸める

### 全体設定/個別設定
全体設定(出力サイズ/余白/拡大率/揃え/透過しきい値/feather/白フチ幅/アップスケール許可)と、行ごとに上書きできる個別設定。

### プレビュー
6×4グリッド表示、背景切替(市松/白/ダークグレー/チャット背景風)、サムネイルクリックで個別設定パネル、デバウンス再描画。

### 書き出し
`stamps_YYYYMMDD_HHMM.zip`(01.png〜24.png)。書き出し前検証(サイズ上限・偶数・容量1MB・24枚揃っているか)。個別PNG保存、検出枠+設定のJSON保存/読込。

`docs/line-spec.md` を参照。値は `src/shared/lineSpec.ts` に集約。

## 6. UI要件

- 1ページ構成、2タブ(「① プロンプト作成」「② 画像分割・書き出し」)。
- 日本語UI、システムフォントのみ(外部フォント禁止)。
- トースト・処理中表示・エラーメッセージを日本語で表示。
- 空状態には次のアクションの案内を表示。
- キーボード操作可能、ボタンにラベル付与、色だけに依存しない。

## 7. 非機能要件

- 外部ネットワーク通信なし(CDN・外部フォント・アナリティクス禁止)。
- 画像処理コアはDOM非依存の純粋関数(`{width, height, data: Uint8ClampedArray}`入出力)。
- 依存パッケージは vite / typescript / vitest / jszip / eslint系(typescript-eslint) / prettier のみ。
