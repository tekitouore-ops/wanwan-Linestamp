# プロンプトテンプレート設計メモ

`src/prompt/fixedText.ts`(固定文言)+`src/prompt/layoutConstants.ts`(数値定数)+`src/prompt/buildPrompt.ts`
(組み立て)が生成する、ChatGPT画像生成向け日本語プロンプトのテンプレート。2026-11-02の仕様変更で、
ユーザーが検証した最終プロンプトをそのまま正本とし、**ほぼ全部を固定文**にした(詳細はdocs/decisions.md参照)。
可変なのは、24行の内容(セリフ・状況)と、任意の2項目(キャラクター補足・追加指示)だけ。

## テンプレート全文

`{...}` はユーザー設定・入力値で置換するプレースホルダ。本文はDOM/UIに依存しない純粋関数
`buildPrompt(rows: StampRow[], settings: PromptSettings): string` として実装し、本ファイルのテンプレートと
テスト(ゴールデンテスト含む)で一致を確認する。

```
添付した参照画像のキャラクターを主人公にして、LINEスタンプ用のイラストシートを、1枚の画像として作成してください。

【画像サイズと配置】
- 画像全体は{画像幅}×{画像高さ}pxの横長
- 横{列数}列×縦{行数}行、合計{マス数}マス
- 各マスは{マス幅}×{マス高さ}px相当で、すべて同じ大きさ
- 左上から右へ、上の段から順に{マス数}個を配置

【キャラクター】
- 同じキャラクターとして認識できるよう、顔・体型・色・線・服装・小物を全マスで統一
- 各マスにキャラクターは1体だけ
- キャラクターの大きさをそろえ、各マスの中央に配置
- キャラクター、文字、頭・手・足・小物、ハート・汗・効果線・光など、すべての要素を各マスの四辺から{外周余白}px以上内側に収める
- 文字とキャラクターを合わせて各マスの中央{安全幅}×{安全高さ}pxの範囲内だけを使い、周囲に透明な余白を残す
- 隣り合う文字・キャラクター・効果の間には、合計{最小すき間}px以上の透明なすき間を作る
- 隣のマスへはみ出さない、キャラクター同士を重ねない
{キャラクター補足がある場合のみ、ここに「- 」+補足文を1行追加}

【文字のルール】
- 各項目の「」内の日本語を、対応するマスに一字一句そのまま入れる
- 誤字・文字化け・別の言葉への変更・文字の省略・余分な文字は禁止
- 文字は太く大きく、スマートフォンでも読みやすい手書き風にする
- 長い文言は2行までで改行し、文字を小さくしすぎない
- 白フチや濃い色のフチを付け、キャラクターと重ならない位置に配置する
- 吹き出しは使わず、文字をキャラクターの近くに直接配置する

【背景と禁止事項】
- 背景は本物の透明背景(アルファチャンネル付きPNG)にする
- 背景色・背景の影・模様・グラデーション・風景を入れない
- キャラクターや文字の周囲に、影・ぼかし・光彩・半透明のにじみを入れない
- 枠線・区切り線・番号・タイトル・ロゴを入れない
- 指定したスタンプ文言以外の文字を入れない
- 白背景や、透明を表す市松模様を描かない
- {マス数}個より多くも少なくもしない

{追加指示がある場合のみ、「【追加指示】」の見出し+本文+空行を、ここに挿入}
【各マスの内容(左上から順に{マス数}個)】
『{セリフ1}』｜{状況1}
『{セリフ2}』｜{状況2}
(……最終行まで同じ形式)
```

## 置換ルール

- `{画像幅}{画像高さ}{列数}{行数}{マス数}{マス幅}{マス高さ}{外周余白}{安全幅}{安全高さ}{最小すき間}`:
  すべて`src/prompt/layoutConstants.ts`の定数から埋め込む(既定値: 1536×1024、6列×4行、24マス、
  256×256px、外周余白24px、安全領域208×208px、最小すき間48px)。
- `{キャラクター補足}`: 未入力なら行自体を出力しない。
- `{追加指示}`: 未入力なら「【追加指示】」の見出しごと出力しない。
- 24行(24マス)の列挙は`『セリフ』｜状況`形式、番号は付けない(並び順がそのままマスの順)。
  状況が空の場合は`｜状況`部分を出さない。セリフ・状況の両方が空でも`『』`として行自体は出力し、位置をずらさない。
  行の整形ルール(前後空白の削除・セル内改行のスペース化・セリフを囲む`『』`/`「」`の二重括弧防止)は
  `buildPrompt.ts`の責務とし、文言はここに書かない。

## 気づいた点(2026-11-02 統合仕様変更時)

- 「文字のルール」節の「各項目の『**」**内』の日本語を…」という文言は、実際の行形式`『セリフ』｜状況`と
  表記が揺れている(「」ではなく『』)。ユーザーからの指示により、検証済みサンプルの文言は変更せずそのまま
  採用した。
- 「背景と禁止事項」節の「風景を入れない」という指示と、状況欄に含まれる背景描写(草原・朝日など)は、
  層が異なる指示(背景透過そのものの指示 vs AIへの演出ヒント)として、こちらも変更せず採用した。
