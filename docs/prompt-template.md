# プロンプトテンプレート設計メモ

`src/prompt/buildPrompt.ts` が組み立てる、ChatGPT画像生成向け日本語プロンプトのテンプレート。
`{...}` はユーザー設定・入力値で置換するプレースホルダ。本文はDOM/UIに依存しない純粋関数
`buildPrompt(rows: StampRow[], settings: PromptSettings): string` として実装し、本ファイルのテンプレートと
テストで一致を確認する。

## テンプレート全文

```
添付した参照画像のキャラクターを主人公にして、LINEスタンプ用のイラストシートを、1枚の画像として作成してください。

【全体レイアウト】
- 画像は横長(3:2、1536×1024px)。
- 6列×4行、合計24個のスタンプイラストを並べる。順序は左上から右へ、上の行から下の行へ(1行目が1〜6番、2行目が7〜12番、3行目が13〜18番、4行目が19〜24番)。
- 各スタンプは、それぞれ約256×256pxの独立したマスの中に収める。隣のスタンプと重ならず、マスからはみ出さない。
- 各スタンプの周囲(マスの端)には十分な余白を残す。
- マス目の線、枠線、区切り線、番号、見出し、ロゴなど、スタンプ以外の要素は一切描かない。
- 背景は画像全体で{背景色}の単色にする。影、グラデーション、地面、模様、テクスチャは背景に入れない。

【キャラクターと画風】
- 参照画像のキャラクターのデザイン、色、質感、線の太さ、画風を、24個すべてで統一する。顔つき・体の比率・色が変わらないようにする。
- 参照画像の背景や構図はまねせず、キャラクターだけを使う。
{キャラクター補足}
- 表情やポーズ、小道具は、各スタンプの「お題」と「状況」に合わせて変える。ただし、同じキャラクターだとひと目で分かること。
- 小道具や背景の一部(木、かご、夕日など)が必要な場合は、そのスタンプのマスの中だけに描く。

【文字(セリフ)】
- セリフがあるスタンプには、キャラクターの近く(主に上側、難しければ横)に日本語の文字を入れる。
- 書体は{書体}。太めで読みやすく、文字色は{文字色}。{文字の縁取り}
- 文字は、指定したとおりに一字一句正確に書く。誤字、欠字、文字化け、別の漢字や記号への置き換えは禁止。
- セリフが「なし」のスタンプには、文字を入れない。

{白フチの指示(設定がONのときのみ)}

【24個の内容】
1番 お題:{お題} / 状況:{状況} / セリフ:「{セリフ}」(なしの場合は「なし」)
2番 ...
(24番まで同じ形式で列挙)

【出力に関する最重要ルール】
- 24個すべてを、必ず1枚の画像の中に描く。数を減らしたり、同じ絵を繰り返したりしない。
- 24個の絵柄は、すべて異なる内容にする。
{追加指示}
```

## 置換ルール

- `{背景色}`: `#FFFFFF` の場合は「純白(#FFFFFF)」、それ以外は `濃い緑色(#2E7D32)` のようにHEXを明記する。
- `{キャラクター補足}`: 未入力なら行自体を出力しない。
- `{書体}`: プリセット文言(例:「手書き風の太い丸ゴシック」)または自由入力文字列。
- `{文字色}`: HEX値そのもの(例: `#5A3A22`)。
- `{文字の縁取り}`: ON→「文字には白い縁取りを付ける。」/ OFF→「文字に縁取りは付けない。」
- `{白フチの指示}`: 設定ONの時のみ「各スタンプのキャラクターと文字の外側に、ステッカーのような白いフチを約6px付ける。」を見出し付きで挿入。既定はOFF(理由: 白フチはツール側`outline.ts`で後付けするため。AIに任せると背景が白のとき境界が不安定になり、自動検出の精度も落ちる)。
- `{追加指示}`: 未入力なら行自体を出力しない。
- 24行の列挙は、空のお題/状況/セリフがあっても行自体は出力し、セリフが空欄の場合は「なし」と明記する。

## 個別再生成プロンプト(Phase 2終盤・余力があれば)

1個のスタンプのみを正方形で再生成させる短縮版テンプレート。キャラクター補足・書体・文字色・縁取り設定は共通テンプレートと同じ値を使う。

```
添付した参照画像のキャラクターと同じデザイン・画風で、LINEスタンプ用のイラストを1個だけ作成してください。

- 画像は正方形(1024×1024px)。背景は{背景色}の単色、余白を十分に残す。
- お題:{お題} / 状況:{状況} / セリフ:「{セリフ}」(なしの場合は「なし」)
- セリフがある場合、書体は{書体}、文字色は{文字色}。{文字の縁取り}指定したとおり一字一句正確に書く。
{キャラクター補足}
- マス目線、枠線、ロゴなど、スタンプ以外の要素は描かない。
```
