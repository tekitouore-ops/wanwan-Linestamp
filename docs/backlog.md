# バックログ(将来拡張の候補)

本ツールの現行スコープ外で、将来検討する拡張候補。優先順位は未定。

- **12枚×2シート方式への対応**: 1枚のシートに24個詰め込むと1個あたりの生成解像度が低くなるため、12枚×2シートに分けて生成解像度を上げる方式。`cols`/`rows`パラメータは既に内部で可変にしてあるため拡張しやすい想定。
- **クロマキー方式**: 背景色を緑などの特殊色にして、色キー的な透過処理の精度を上げる方式。現行は白背景+連結領域フラッドフィル方式。
- **個別スタンプの再生成→差し替え**: 1個だけ出来が悪い場合に、個別再生成プロンプト(未設計。下記「個別再生成プロンプト(タブ①)」参照)で作った画像を、シートの該当枠にはめ込んで差し替える機能。
- **アニメーションスタンプ対応**: APNG形式、フレーム数・タイミングの規格に対応する拡張。本ツールの静止画パイプラインとは別の検討が必要。
- **GitHub Pagesでの公開**: Phase 5で `deploy.yml` を用意する。公開設定(Settings → Pages → Source → GitHub Actions)はユーザー側の手動作業。
- **Web Workerへの処理オフロード**: 検出・フラッドフィル処理が重い場合に、UIスレッドのカクつきを避けるためWorkerに逃がす。現行はメインスレッドで実装し、問題が出た場合に対応する想定。
- **個別再生成プロンプト(タブ①)**: 各行に「この1個だけ再生成するプロンプトを作る」ボタンを追加する。2026-11-02の仕様変更でプロンプト本文を固定文化したため、短縮版テンプレートは未設計(着手時に`docs/prompt-template.md`へ追記する)。Phase 2では見送った(docs/decisions.md参照)。
- **偽の市松模様背景の自動除去**: ChatGPTが「透明の代わりに市松模様(チェッカーパターン)を描いてしまう」場合の自動検出・除去。2026-11-02の複数シート対応版では対象外とし、ユーザーが手動で背景色モードに切り替える運用とした。
- **文字領域だけ、別の幅の白フチを付ける機能**: 縁フチは現行「文字を含む全体に1つの白フチ」のみに統一している(2026-11-03、修正指示書 項目8)。キャラクターとセリフ文字で別幅の縁フチを付けたい場合の拡張は見送り。
- **favicon.svgのデザイン変更**: 柴おにぎり風など、現行のプレースホルダーから差し替える案(2026-11-03、修正指示書 項目10で対応見送り)。
- **容量(KB)算出のパフォーマンス対策**: 書き出し前検証でのPNGサイズ算出が重いと感じた場合のみ対応(2026-11-03、修正指示書 項目10)。
- **手動消しゴムのなげなわ(囲んで消す)ツール**: ブラシでの塗りに加え、範囲を線で囲んで内部をまとめて消すツール。広い範囲を消したい場合にブラシより速いが、自己交差のある多角形の内外判定など実装がやや複雑なため、今回(追加修正指示書 第5弾 項目19)は見送った。
- **手動消しゴムマスクのコピー(他スタンプ/他シートへ)**: 同じような位置に同じようなもやがある場合に、1枚で作ったマスクを他のスタンプ番号・他の採用元シートへコピーできる機能。マスクはシート絶対座標で保存しているため、コピー先の枠位置に応じた再配置(`alignEraseMaskToCrop`の活用)が必要になる。今回(追加修正指示書 第5弾 項目19)は見送った。
- **ゴミ除去・手動消しゴムの「確かな前景」可視化デバッグオーバーレイ**: `solidAlphaMin`以上のアルファを持つ「確かな前景」として保護される範囲を、画面上に可視化するオプション。ゴミ除去が効きすぎ/効かなすぎる原因を調べやすくなるが、優先度が低いため、追加修正指示書 第3弾・第5弾(項目15・18・19)のいずれでも実装を見送った。
