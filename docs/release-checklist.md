# 最終チェックリスト(LINE Creators Marketへの提出前)

LINE Creators Marketへスタンプを提出する前に、人が実機で確認するためのチェックリストです。
追加修正指示書 第7弾 項目26で新設しました。README.mdからもリンクしています。

## A. 準備

- [ ] 参照画像(キャラの元絵)がある
- [ ] 24個の『セリフ』と状況を決めた(セリフが長すぎず、スマホで読める)
- [ ] LINE Creators Marketの最新ガイドラインを、公式サイトで確認した(下記の「要公式確認」項目)

## B. プロンプト生成(タブ①)

- [ ] 『セリフ』｜状況 を貼り付けて、24行が正しく入った
- [ ] セリフ・状況の空欄の警告を確認した
- [ ] プロンプト全文をコピーした(「背景と禁止事項」に、にじみ禁止の1行が入っている)
- [ ] 「画像をコピー」で参照画像もコピーし、ChatGPTに両方を貼り付けた
- [ ] 生成されたシートで、24個が重ならず、文字が正確か確認した(誤字は、その枠だけ再生成して別シートにする)

## C. 分割・検出(タブ②)

- [ ] シートを読み込み、24個の枠が付いた(透過/背景色のモードが正しいか確認)
- [ ] 警告のある枠を確認し、枠の位置・大きさを直した
- [ ] 複数シートを使う場合、番号ごとの採用元を確認した

## D. 調整(ステップB)

- [ ] 確認用の背景を、**黒**・白・市松で切り替えて、全24枚を確認した
- [ ] 文字・キャラの白フチが、欠けたり二重になったりしていない
- [ ] キャラの周りに、白いもや・灰色のにじみが残っていない(ゴミ除去、消しゴムで対応)
- [ ] 被写体が、画像の端で切れていない(余白がある)
- [ ] 解像度の警告(赤)が出ているものを確認した(黄色は許容範囲か判断)
- [ ] 表紙(メイン画像)を決めた

## E. 書き出し・検証

- [ ] ZIPを書き出した
- [ ] `npm run verify:zip -- <ZIPのパス>` を実行し、NG が 0件
- [ ] 「注意」の項目を、1件ずつ確認した
- [ ] ZIPを展開し、全PNGを、実機のLINEまたは画像ビューアで、ライト/ダークの両背景で確認した
- [ ] 設定JSONを保存し、読み込み直して、調整内容が戻ることを確認した(作業の再開用)

## F. LINE Creators Market への提出(要公式確認)

下記は、本ツールが前提にしている値であり、**公式ガイドラインの最新版で必ず確認する**こと。変更されている場合は、`src/shared/lineSpec.ts` を更新する。

- [ ] スタンプ画像のサイズ(最大 370×320、偶数)
- [ ] メイン画像(240×240)、トーク一覧タブ画像(96×74)の規格
- [ ] ファイル形式(PNG、背景透過)、容量上限
- [ ] 色空間・解像度などの形式要件(RGB、dpi など)
- [ ] 1セットの枚数(8/16/24/32/40のうち、選んだ枚数)
- [ ] ZIPでアップロードする場合の、ファイル名と総容量の制限
- [ ] 生成AIを使った作品の取り扱いルール(申告や、禁止事項の有無)
- [ ] キャラクター・文字・小道具に、他者の著作物・商標に当たるものがない
- [ ] 審査のガイドライン(禁止表現、文字の読みやすさなど)に反していない

## G. 結果の記録

- [ ] 見つかった不具合・要望を、docs/backlog.md に追記した
