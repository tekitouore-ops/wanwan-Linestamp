# LINEスタンプ規格メモ

> **注意**: 本メモはツール開発時点での理解をまとめた参考情報です。実際にLINEスタンプを申請する前に、必ず
> [LINE Creators Market](https://creator.line.me/) 公式の最新ガイドラインを確認してください。
> 規格(サイズ・容量・枚数など)は変更される場合があります。

## 本ツールが扱う規格(静止画スタンプ)

| 項目                       | 値                                |
| -------------------------- | --------------------------------- |
| 画像の最大サイズ           | 370 × 320 px                      |
| 幅・高さ                   | 偶数であること                    |
| ファイル形式               | PNG(背景透過)                     |
| 1枚あたりの容量上限        | 1MB                               |
| 画像周囲の推奨余白         | 約10px                            |
| セット枚数(本ツールの対象) | 24枚 固定                         |
| ファイル名規則             | `01.png` 〜 `24.png`(2桁ゼロ埋め) |

これらの値は `src/shared/lineSpec.ts` に定数として集約し、変更が1箇所で済むようにする。

## メイン画像・タブ画像(2026-11-02〜対応)

スタンプ一覧でのサムネイル・タブアイコンに使われる画像。本ツールでは、ユーザーが指定した「表紙」スタンプ
(既定は01番)から自動生成し、書き出しZIPに含める。

| 項目       | ファイル名 | サイズ       |
| ---------- | ---------- | ------------ |
| メイン画像 | `main.png` | 240 × 240 px |
| タブ画像   | `tab.png`  | 96 × 74 px   |

タブ画像の出力有無はUIのチェックボックス(既定ON)で切り替えられる。いずれも `src/shared/lineSpec.ts` に
サイズ・ファイル名を定数として定義する。

## セット枚数のバリエーション(参考・lineSpec側で保持)

LINE Creators Marketでは8/16/24/32/40枚などのセット構成が選べるが、**本ツールでは24枚のみを対象**とする。
将来の拡張に備えて `lineSpec.ts` 内には候補値として保持しておく(docs/backlog.md参照)。

## 審査・利用ルールに関する注意

- LINE Creators Marketの審査ガイドライン(表現規制、著作権、商標など)は本ツールの対象外。申請前に公式ガイドラインを必ず確認すること。
- 生成AI(ChatGPT画像生成など)を使って作成したスタンプの取り扱いについても、LINE側の規約・ポリシーを確認すること。本ツールはプロンプト作成と画像の後処理(切り出し・透過・規格化)のみを行い、生成AIの利用規約の遵守はユーザーの責任とする。
