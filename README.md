# wanwan-Linestamp

LINEスタンプ(静止画24個セット)の制作を助けるブラウザ内ツールです。すべての処理はブラウザ内で完結し、
画像を外部サーバーに送信することはありません。

## できること

1. **プロンプト作成(タブ①)**: 参照キャラクター画像と、24個分の「お題・状況・セリフ」の入力から、
   ChatGPTの画像生成に貼り付ける日本語プロンプトを作成します。
2. **画像分割・書き出し(タブ②)**: ChatGPTが生成した「24個のスタンプが1枚に並んだシート画像」(6列×4行)を
   自動検出で24枚に切り出し、微調整したうえで、LINEスタンプ規格のPNG(背景透過)としてZIPにまとめて書き出します。

画像生成そのものはこのツールでは行いません。プロンプトを作るところまでがタブ①の役割で、
実際の生成はユーザーがChatGPT上で行います。

## 使い方

1. タブ①で参照画像(キャラクターの元絵)を登録し、24行の表に「お題」「状況」「セリフ」を入力します
   (CSV/TSVの貼り付けにも対応しています)。
2. 「プロンプトを生成」→「クリップボードにコピー」します。
3. ChatGPTに参照画像を添付したうえで、コピーしたプロンプトを貼って画像を生成します。
4. 生成された1枚のシート画像(6列×4行、24個のイラスト)をダウンロードします。
5. タブ②【ステップA】でそのシート画像をアップロードします。自動検出で24個の枠が付くので、
   ズレがあれば枠をドラッグ・リサイズして微調整します(背景色が特殊な場合はスポイトで
   背景色を指定し直してから「再検出」できます。自動検出がうまくいかない場合は「均等分割」に
   切り替えることもできます)。「この枠で確定」で次へ進みます。
6. 【ステップB】右側に24枚のカードが並びます。カードを選ぶと、左側の調整パネルで
   「縁補正・縁フチ・切り抜き・拡大・位置」を1枚ずつ調整できます(スライダーと数値入力の
   どちらでも操作でき、ダブルクリックでその項目だけ初期値に戻せます)。確認用の背景(市松模様・
   任意の色)を切り替えて見た目を確認できます(書き出す画像自体は常に透過のままです)。
   お気に入りの1枚を「表紙に設定」すると、そのスタンプを元にメイン画像・タブ画像が作られます。
7. 「ZIPで書き出し」で `01.png`〜`24.png`・`main.png`(240×240)・`tab.png`(96×74)を含む
   ZIPをダウンロードします。書き出し前にサイズ・容量・空欄チェックを行い、問題があれば警告を
   表示します。

### 動作環境

- 対応ブラウザ: 最新版のGoogle Chrome / Safari / Microsoft Edge(デスクトップ向け。スマートフォン対応は想定していません)。
- インターネット接続は不要です(初回読み込み後は外部通信を一切行いません)。

### ChatGPTでの生成のコツ

- 参照画像は必ずプロンプトと一緒に添付してください(プロンプト文中に画像は埋め込めません)。
- 背景色は単色(既定は白)にすると、タブ②の自動検出・透過処理が安定します。
- プロンプトの「白フチ」はツール側(タブ②)で後から付けるため、既定では生成時に指示しません。
  生成画像に最初から白フチが付いていると、自動検出の精度が落ちることがあります。

## ローカル開発手順

Node.js LTS(20以上。`.nvmrc` 参照)を使用してください。

```bash
npm install
npm run dev
```

ブラウザで案内されたURL(既定 `http://localhost:5173/wanwan-Linestamp/`)を開きます。

### その他のコマンド

```bash
npm run build       # 本番ビルド(dist/ に出力)
npm run preview     # ビルド結果をローカルで確認
npm test            # Vitestでユニットテストを実行
npm run typecheck   # TypeScriptの型チェック
npm run lint        # ESLint
npm run format      # Prettierでフォーマット
```

## ビルドと公開(GitHub Pages)

このリポジトリは GitHub Pages (`https://tekitouore-ops.github.io/wanwan-Linestamp/`) での公開を想定しています。
`.github/workflows/deploy.yml` が `main` への push(または手動実行)をトリガーに、型チェック・Lint・テスト・
ビルドを行ったうえでGitHub Pagesへデプロイします。

公開を有効にするには、リポジトリの **Settings → Pages → Source** を **GitHub Actions** に変更してください
(この設定変更はリポジトリ管理者が手動で行う必要があります)。

## フォルダ構成

```
wanwan-Linestamp/
├── docs/            # 仕様書・設計ドキュメント(spec / line-spec / prompt-template / architecture / decisions / backlog)
├── public/          # 静的ファイル(favicon等)

│   ├── main.ts      # エントリポイント
│   ├── ui/          # 共通UI部品(タブ、スライダー等)
│   ├── prompt/      # 機能1: プロンプト生成
│   ├── split/       # 機能2: 検出・ステップA/B画面(検出・カード一覧・調整パネル等)
│   ├── export/      # 機能2: 規格化・書き出し(背景透過・縁補正・配置・縁フチ・ZIP等)
│   └── shared/      # 共通基盤(LINE規格定数・ImageDataラッパー・ストア等)

```

詳細は `docs/architecture.md` を参照してください。

## LINEスタンプ規格について

本ツールが前提とする規格(最大サイズ370×320px、PNG透過、24枚セット等)は `docs/line-spec.md` に
まとめています。**実際に申請する前に、必ず [LINE Creators Market](https://creator.line.me/) 公式の
最新ガイドラインを確認してください。** 規格は変更される場合があります。

## 注意事項

- LINE Creators Marketの審査ガイドライン(表現・著作権・商標など)は本ツールの対象外です。申請前に公式ガイドラインを確認してください。
- 生成AIで作成した画像の取り扱いについても、LINE側の利用規約・ポリシーをご確認ください。本ツールはプロンプト作成と画像の後処理(切り出し・透過・規格化)のみを行います。
- このツールは外部ネットワーク通信を行いません。ユーザーの画像はブラウザ内でのみ処理され、どこにも送信されません。
